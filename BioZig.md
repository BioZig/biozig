BioZig

Tagline

Biological computation built on first-principles representations.

⸻

Mission

BioZig aims to provide a modern computational biology foundation that is:

* Fast
* Memory efficient
* Deterministic
* Reproducible
* Interoperable

The project is implemented in Zig while remaining accessible from multiple programming languages through a stable C ABI.

⸻

Design Goals

1. Biological-first architecture
2. High-performance execution
3. Compact biological representations
4. Deterministic results
5. Cross-platform support
6. Language interoperability
7. Publication-ready workflows

⸻

Core Biological Philosophy

DNA is not a string.

Protein is not a string.

Biological entities should be represented using structures that reflect their underlying biological properties.

Examples include:

* Packed nucleotide representations
* Compact amino acid encodings
* Domain-specific biological graph structures
