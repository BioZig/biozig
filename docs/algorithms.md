# Algorithms

The `algorithms` module provides the core computational procedures for molecular, structural, and evolutionary biology.

## Molecular Algorithms

### Sequence Alignment
- **Needleman-Wunsch:** Global alignment using dynamic programming matrix.
- **Multiple Sequence Alignment (MSA):** Progressive Center-Star alignment.
- **Suffix Tries:** String index construction for pattern matching.

### Motif Discovery
- **Gibbs Sampler:** Markov Chain Monte Carlo algorithm to find conserved motifs.
- **Hidden Markov Models (HMM):** Viterbi decoding and Forward-Backward algorithms.

## Structural Algorithms
- **Kabsch Algorithm:** Calculates the optimal rotation matrix to minimize root-mean-square deviation (RMSD) between two paired sets of 3D points using Singular Value Decomposition.
